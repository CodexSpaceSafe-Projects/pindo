# 云同步状态

2026-11-14 起，macOS 和 Android 已移除缤纷云连接界面、实际网络客户端、S3 签名及自动轮询。当前版本仅在本机保存，设置会明确显示 Cloudflare 同步正在开发。

本机事项、分组、备注、旧同步副本、墓碑、资料库归档、待确认的连接事务和冻结发件箱均继续保留。旧 Keychain / Keystore 凭据不会在启动时读取、自动连接或删除。离线编辑继续落盘，旧发件箱不会因新的本机编辑被假确认。没有修改或删除旧云端对象。

普通 JSON 导出和快照仍然只包含可见资料，不包含恢复密钥、设备令牌、连接日志、资料库归档和发件箱。需要保留完整旧库恢复能力时，应同时保留原设备的应用数据与系统安全存储；单独导出待办 JSON 不包含这些信息。

## Cloudflare v3 首批实现

- Swift / Kotlin 的库身份、规范 AAD、AES-256-GCM 加密字节、整数边界与备注因果寄存器参考实现。
- `backend/cloudflare/` 中独立的 Worker TypeScript、D1 migration、主库 `info / push / pull / receipts` 开发接口。
- 一次 D1 batch 完成条件追加、轻量回执与独立 head 推进；保留回执、校验撤销 / epoch / 预算，回执与应用游标各自独立。
- 共享协议向量与真实 workerd / 本地 D1 的并发、回滚、重试、撤销和 GC 边界测试。

这是 P0 / P3 的基础提交，尚未完成 P0 全部操作契约，也不是可用的双端云同步。P1 字段操作、P2 SQLite 事务存储、P3 配对 / artifact、P4 连接接入、P5 检查点与安全回收、P6 真云与实机验收仍需后续实现。现已提供独立 Cloudflare staging 部署配置和健康检查，生产模式仍被配置拒绝。客户端尚不能连接测试服务。

本次按“删除缤纷云支持”的要求取消了方案中的旧 S3 在线只读桥接；保留本机旧格式解码与恢复资料。晚到旧 S3 PUT 不会被此版本继续自动吸收，旧源需要用户另行保留。不能将旧 v2 密文直接投递为 v3 批次。

具体契约、待冻结项与后续顺序见 [CLOUDFLARE-V3.md](CLOUDFLARE-V3.md)，开发验证见 [VALIDATION.md](../VALIDATION.md)。
