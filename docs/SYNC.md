# 缤纷云加密同步

Pindo 使用每位用户自己的缤纷云账号，不提供公共共享账号。macOS 与 Android 使用相同的 S3 协议和加密格式；离线可正常编辑，联网后合并。

## 连接设备

1. 注册并实名认证[缤纷云](https://console.bitiful.com/)，创建一个私有存储桶。
2. 创建仅能访问该存储桶的子用户 Access Key / Secret Key，授权列举对象、读取对象、写入对象。应用不会创建桶、公开桶或删除云端文件。
3. macOS 打开「设置 → 云同步」；Android 打开「云同步」。填写桶名、端点、区域和凭据。默认端点为 `https://s3.bitiful.net`，区域 `cn-east-1`；其他区域以控制台提供的值为准。仅接受缤纷云的 HTTPS 端点。
4. 第一台设备点击「生成新密钥」，把恢复密钥保存到自己的密码管理器，再保存并连接。其他设备填写**相同桶、区域和恢复密钥**；不重新生成密钥。不同恢复密钥会进入不同的同步资料库。
5. 两端分别点击「立即同步」，验证新增、备注、完成状态和分组。凭据只在应用里填写，不提交到 GitHub、不发送到聊天。

恢复密钥是随机 256 位密钥，以 64 位十六进制显示。macOS 凭据和密钥保存在本机 Keychain；Android 使用 Android Keystore 的 AES-GCM 密钥加密保存，禁用系统云备份。云端不保存恢复密钥，丢失后不能通过云账号找回明文；本地仍可读取自己的数据。

断开连接仅移除本机凭据并停止网络请求，保留本地待办及云端密文。要彻底清空云端，请在缤纷云控制台自行删除对应目录。不要在其他设备离线时手动删除单个设备文件，否则尚未合并的更改可能丢失。

## 同步行为

- 修改先原子保存到本地，再尝试上传。前台检查间隔约 30 秒；macOS 无可见窗口时减少到约 60 秒。网络失败采用退避重试，手动同步可立即重试。Android 离开前台后不承诺即时同步，返回应用时继续检查。
- 正在编辑备注、编辑事项或拖动时，macOS 暂停应用远端变更，结束后继续，避免替换输入中的内容。
- 同步待办、三级父子关系、顺序、状态、日期、备注和分组。外观、快捷键、登录启动、草稿和本地快照仍属于各设备。
- 各字段使用 Lamport 逻辑时钟及设备 ID 排序。不同字段可分别合并，同一普通字段并发修改时使用确定性的获胜值。并发备注保留多个版本，以 `[Sync conflict]` 分隔；编辑合并后的备注可解决冲突。
- 删除保留墓碑，避免离线设备把旧事项重新带回。恢复历史快照会记录为新的本地更改。暂不自动清理墓碑或云端设备文件。
- 并发移动产生的环、失去父项和超过三级的层级会确定性地提升为主待办，保留内容。父项状态自底向上按子项重新计算。
- 首次连接会合并各设备已有内容。不同 ID 的默认分组或同名待办不会按名称自动去重；重复分组名称会带 ID 后缀。

存储对象本身没有实时推送，本版为自动轮询同步。请求额度按整个云账号共享；每次检查至少一次列举请求，发生变化时另有下载、上传请求。按[官方计费规则](https://docs.bitiful.com/prices/basic)，S4 免费额度为每月 10 万次请求（每日免费上限 1 万次）、每月 10GB 直接出口流量（每日免费上限 5GB），CDN 的额度不能挪作直连额度。平台政策可变，实际以控制台为准。

## 数据格式 v1

每个安装实例仅写自己的 `pindo/v1/<vaultID>/heads/<deviceID>.json`，内容是完整合并状态的加密副本；不覆盖其他设备的对象。列举使用 ETag 判断哪些对象需要读取。

- 主密钥：随机 32 字节；`vaultID = SHA256(key).hexLowercase.prefix(32)`。
- AES-256-GCM：随机 12 字节 nonce，16 字节 tag；AAD 为 UTF-8 `PindoSync/v1/<vaultID>`。
- 外层 JSON：`{"version":1,"nonce":"base64","ciphertext":"base64","tag":"base64"}`，Base64 使用标准字母表。
- 明文 `SyncPayload`：`version`、`seen`（各设备已知最大计数器）和 `records`。
- 记录键为 `task:<lowercaseUUID>` 或 `group:<lowercaseUUID>`。字段寄存器为 `{value, stamp:{counter,deviceID}}`，`$alive` 记录存在/删除。任务的 `note` 单独保存在 `notes:[{value,stamp,seen}]`，支持并发版本。
- 日期沿用 Swift 现有格式：日期时间为 **2001-01-01 UTC 起的秒数**（转换 Unix 秒需加 978307200）；计划日为 `{year,month,day}`。本机模型可读取不同大小写的 UUID；同步记录键、引用和设备 ID 统一使用小写。
- 本地文档与副本、基线在一个原子文件中提交。导出的明文资料和快照不含同步副本、S3 凭据或恢复密钥。

当前限制为每个资料库最多 100 个设备文件，单个同步明文最多 7MiB，加密后的对象最多 10MiB；macOS 与 Android 使用相同限制。超过限制、未知版本、解密失败或格式错误会报错，不自动清空或替换本地数据。

## 验证边界

自动测试覆盖字段合并、删除、备注冲突、层级投影、写入失败，以及固定 AES-GCM 和 SigV4 向量。macOS 原生编译与界面测试由 macOS CI 执行，Android 使用 Gradle 单元测试、lint 和 APK 构建。

未配置真实云桶时，模拟网络及固定向量不等于已经验证了真实缤纷云连通性，也不能证明中国大陆各运营商的延迟。正式使用前在自己的桶上完成双设备同步检查；设备后台调度和界面操作还需实机验收。
